# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- **Primary Audience**: Prospective freelance clients, startup founders, and businesses seeking high-quality contract software engineering (Mobile & Full-Stack).
- **Secondary Audience**: Engineering peers and recruiters evaluating technical depth, clean architecture, and product craftsmanship.

## Product Purpose

Serve as an interactive, high-converting digital portfolio and proof-of-work engine that demonstrates end-to-end engineering excellence (Flutter, Appwrite, Spring Boot, React, Supabase) and converts visitors into client contracts and project collaborations.

## Positioning

"From paper ball to paper plane" — a full-stack engineer who bridges beautiful, cinematic frontend design with robust clean architecture and production-ready backend systems. Unlike generic portfolio templates, this site demonstrates real interactive capabilities (live payment/tipping integration, cinematic motion, case-study level project breakdowns).

## Operating Context

- Evaluated primarily on desktop and mobile web browsers by busy clients and technical decision-makers.
- Needs fast initial page paint, seamless micro-interactions, clear contact channels (EmailJS, GitHub, direct links), and undeniable proof of delivered work.

## Capabilities and Constraints

- **Stack**: React 19, TypeScript, Vite, Tailwind CSS v4, TanStack Router/Start, Framer Motion, Radix UI / shadcn/ui, Supabase, Lucide icons, Cursor, Antigravity 2.0, Claude LLMs, Model Context Protocol (MCP).
- **Architectural Pattern**: Clean Architecture (Presentation, Domain, Data, Usecases separation) & Agentic Workflows (MCP Tool Servers, SKILL.md, .agents/ rules).
- **Key Modules**:
  - Hero with cinematic cursor and value proposition.
  - Interactive Skills & AI Engineering bento puzzle summary.
  - Interactive Payment / Tipping showcase (Stripe / PayPal / Supabase integration).
  - Detailed Projects timeline & media showcase (videos, screenshots, tech stack tags, architecture notes).
  - Responsive contact form with toast notifications (Sonner).

## Brand Commitments

- **Tone & Identity**: Cinematic, modern, polished, technically rigorous, confident without bloat.
- **Visual Style**: Sleek dark mode foundation, fluid gradients, tactile micro-animations, glassmorphic accents, and refined typography.
- **Name**: Noureldin Adawy (Noureldin).

## Evidence on Hand

- **Production Project Data**:
  - `Whatsunity`: Offline-first multi-tenant residential operating system (Flutter, Dart 3, Appwrite Multi-Database, SQLite Master, Telegram API, Cloudflare R2, BLoC, interactive 20+ screen catalog and Before/After evolution).
  - `Medicare`: Medical services platform (React, Spring Boot, MySQL, REST, screenshots at `public/assets/projects/Medicare/`).
  - Additional projects in `src/features/portfolio/data/projects.data.ts`.
- **Live Functional Integrations**: Working Supabase client, Stripe/PayPal showcase, EmailJS contact integration.

## Product Principles

1. **Craft Over Noise**: Every animation and interaction must feel intentional, fluid, and responsive rather than decorative clutter.
2. **Immediate Proof of Value**: Lead with tangible results, real demo assets, and deep technical breakdowns over vague claims.
3. **Frictionless Conversion**: Make contacting, reviewing projects, and evaluating stack competence effortless from any section of the page.
4. **Architectural Rigor**: Maintain clean separation of concerns in code so the portfolio itself reflects production engineering standards.

## Accessibility & Inclusion

- Responsive design across mobile, tablet, and widescreen viewports.
- Clear contrast ratios for dark theme legibility.
- Semantic HTML markup with accessible interactive controls and keyboard navigability.
